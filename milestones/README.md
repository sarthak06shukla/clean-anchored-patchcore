# Historical project milestones

- `preliminary-report.pdf`: the original proposal, containing planned experiments.
- `midterm-report.pdf`: the one-category, one-seed, 1,024-vector pilot with unreweighted image scores.

These are historical documents. Their proposed/pending-work statements and pilot
metrics describe their original stages. The final paper, report and `results/`
directory at the repository root supersede them. Pilot measurements are not pooled
with the final study.
